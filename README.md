# Object-Oriented Library Manager

A C++ Library Management System developed using Object-Oriented Programming concepts.

## Features

- Add books
- Add members
- Issue books
- Return books
- Search books
- Check book availability
- Display members
- Display issued books
- File persistence
- Automatic data loading

## OOP Concepts Used

- Classes and Objects
- Encapsulation
- Private data members
- Public member functions
- Collections using vector
- File handling
- Multi-file project structure

## Classes

### Book
Stores:
- Book ID
- Title
- Author
- Availability

### Member
Stores:
- Member ID
- Member Name

### Loan
Stores:
- Book ID
- Member ID
